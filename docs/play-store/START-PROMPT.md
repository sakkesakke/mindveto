# Startbericht voor de nieuwe chat

Kopieer alles in het grijze blok hieronder en plak het als eerste bericht in een nieuwe Claude Code-chat
met de repo **sakkesakke/mindveto**.

```
Goal: get the Mindveto Android app live on Google Play.

Read first, in this order:
1. docs/play-store/README.md and files 0 to 6 in docs/play-store/ (this repo, sakkesakke/mindveto).
   File 0 is about the website mindveto.app itself.
2. This repo's CLAUDE.md (site rules: 8 languages, no trackers, honest limits, checks before merge).
3. The app code lives in sakkesakke/geopolcoins, folder human-override/android/ (attach it with add_repo, push access).
   Read its CLAUDE.md and docs/HANDOFF.md. docs/google-play.md there is the old 10 Nov plan; docs/play-store/ replaces it.

Rules:
- I am the owner, a beginner. Answer me in simple Dutch, with numbered steps and exact button names.
- Never invent facts. Google's rules change: open the official pages in docs/play-store/6-check-on-the-day.md on the day
  and write down what you checked. If a host is blocked, ask to allow it (environment network), don't guess.
- Never ask me for passwords, keys or codes in the chat. Never sign in for me. I click Submit / Send for review / Publish
  myself, after you show me what will be sent.
- No crypto, no $MAIGA, no links to geopolcoins pages in the app or on mindveto.app.
- Work in small PRs, checks green, squash-merge. Do not change the site without updating all 8 languages.

Start by:
1. Asking me the 4 decisions in docs/play-store/README.md (package name, donate button, free or paid at launch,
   personal or organisation account). Wait for my answers.
2. Then make the code fixes in docs/play-store/2-fix-before-upload.md in sakkesakke/geopolcoins and test them.
3. Then guide me through docs/play-store/5-stappen-eigenaar.md one step at a time.
```

Tip: zet je antwoorden op de 4 vragen er meteen onder als je ze al weet, bijvoorbeeld:
"1. ja, app.mindveto 2. weg 3. eerst gratis 4. persoonlijk".
